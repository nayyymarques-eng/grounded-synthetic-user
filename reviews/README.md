# Reviews

The reports land here, one per role and review: `YYYY-MM-DD-<what>-<role>.md`, and the verifier's `YYYY-MM-DD-<what>-verified.md`. The rules watch writes `YYYY-MM-DD-rules-watch.md`.

Each report lists the ID of every rule it checked, so a search for a rule ID finds every review to run again when that rule changes.
